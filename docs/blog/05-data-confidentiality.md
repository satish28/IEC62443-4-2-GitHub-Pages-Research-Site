# FR4 — Data Confidentiality

## What Information Must Be Protected?

Industrial components can process information that should not be unnecessarily exposed, such as credentials, configuration, diagnostic information and security parameters.

### Demonstration

Compare an intentionally exposed communication path with a protected implementation at the appropriate laboratory layer.

The engineering question is:

> **What information is sensitive, who can observe it, and what protection is appropriate?**

### Evidence

Traffic captures, configuration comparison and protected communication results.

### Engineering takeaway

Confidentiality decisions should follow the information, architecture and security requirements.
